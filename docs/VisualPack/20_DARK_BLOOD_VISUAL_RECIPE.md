# DARK BLOOD – DAS REZEPT

Dieses Paket ist der Produktionsfahrplan für die Umwandlung der vorhandenen Phase-5-Greybox in die visuelle Zielqualität.

## Reihenfolge
1. Quellen/Lizenzen prüfen.
2. MetaHuman Creator und Game Animation Sample legitim im eigenen Epic/Fab-Konto bereitstellen.
3. CC0-Natur/PBR-Assets aus Poly Haven beschaffen.
4. AI-sichere kostenlose Fab-Assets aus dem Manifest beziehen.
5. Claude Code bekommt diese ZIP + das aktuelle DARK-BLOOD-Projekt.
6. Claude liest `18_CLAUDE_VISUAL_CHARACTER_TASK.md`.
7. Claude legt Visual-/Character-/Animation-Abstraktionen und Content-Struktur an.
8. Ein kleiner Visual Slice wird vollständig auf Zieloptik gebracht.
9. Erst nach Abnahme auf weitere Regionen skalieren.

## Warum keine fertigen fremden Charakter-/Animationsdateien in der ZIP liegen
MetaHuman-, Epic-Sample-, Mixamo- und viele Fab-Inhalte dürfen nicht einfach als eigenständige Rohasset-Sammlung weiterverteilt werden. Deshalb enthält diese ZIP die Integrationsrezepte, Manifeste, Zielbilder und Tools. Der Nutzer bezieht die jeweiligen Assets legitim im eigenen Account; Claude integriert sie anschließend im Projekt, soweit die jeweilige Lizenz/AI-Regel dies erlaubt.
